# The Polite Scraper

A small web scraping project for the FlyRank Backend Development internship.

## Target classification

- **Target:** Books to Scrape
- **Purpose:** This website is a practice sandbox designed for learning web scraping.
- **Scope:** Only the first 3 catalogue pages (60 books).
- **Data collected:** Book title, product URL, price, availability, rating, description, source page, and fetch time.
- **robots.txt:** No robots file found (HTTP 404).
- **Why this is appropriate:** Books to Scrape is specifically provided as a sandbox for practising web scraping.

I will not reuse this code on another site without checking its rules and terms first.
